# Linux Themed Portfolio

This is a personal portfolio website with a Linux terminal theme. It's built with HTML, CSS, and vanilla JavaScript.

## Features

- **Interactive Terminal:** The portfolio is presented as a Linux terminal, where users can type commands to get information.
- **Static Content:** Key information like "About," "Experience," "Projects," "Skills," and "Education" is always visible.
- **Terminal Commands:** The terminal provides commands like `contact`, `photo`, and `clear`.
- **Responsive Design:** The layout is designed to work on different screen sizes.

## How to Use

1.  Clone the repository.
2.  Open `index.html` in your browser.
3.  The main content is displayed on the page.
4.  Use the terminal at the bottom to execute commands.
    - `contact`: Shows contact information.
    - `photo`: Displays a photo.
    - `clear`: Clears the terminal output.

## Deployment

This portfolio is designed to be deployed on GitHub Pages. Simply push the code to a repository and enable GitHub Pages in the repository settings.

## Customization

1.  **Content:** Edit `index.html` to change the static content.
2.  **Terminal Commands:** Modify the `commands` object in `js/main.js` to add, remove, or edit terminal commands.
3.  **Styling:** Change the colors, fonts, and layout in `css/style.css`.
4.  **Photo:** Replace `aswin.jpeg` with your own photo.
